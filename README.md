# finance-tracking-app

Public assets for Copilot MN's App Store listing and review:

- **Privacy policy**: served at the Pages root (`index.html`).
- **`demo-statement.pdf`**: a synthetic Khan Bank statement (made-up name, made-up
  amounts) for App Review — a reviewer has no Mongolian bank account, so this gives them
  a file to import and see the app's categorization feature actually work. Generated by
  `api/scripts/generate_demo_statement.py` in the main app repository and verified to
  round-trip through the real parser before being committed here.

This repo intentionally contains no application source code.
